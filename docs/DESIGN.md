# 拾影界面约定

这是一个 Windows 单用途视频保存工具。页面围绕一次下载，不设置侧栏、营销模块和虚构下载记录。

配色：纸白 #FFFFFF、工作区浅灰 #F5F7FA、墨蓝 #17243C、正文灰 #56647A、操作蓝 #2155CD、成功绿 #24704E。错误使用深红 #B33939，并始终配合文字。

字体使用本机 Segoe UI Variable / Microsoft YaHei UI，避免加载远程字体。标题 30px，区域标题 17px，正文 14–15px，辅助文字不低于 12px。

布局为顶部小型标识、左对齐标题、左右双栏工作区。左栏放链接输入与解析结果，右栏放保存位置和下载选项；窄屏按操作顺序堆叠。视频缩略图是页面的主要视觉内容，空状态用简洁胶片图形引导粘贴。

设计技能的搜索结果侧重营销页面，与本项目不匹配，因此只采纳清晰层级、可见焦点和加载反馈这些通用原则。本页采用上述针对桌面工具制定的布局与色彩，不沿用搜索结果中的落地页结构。

所有交互必须有真实实现。等待状态可取消，错误信息给出下一步；目录和登录信息文件使用系统选择器。模态设置支持 Escape 关闭和焦点管理。尊重减少动态效果设置。
