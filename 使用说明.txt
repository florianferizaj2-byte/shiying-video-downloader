拾影 0.1.0 · Windows 10 / 11 64 位

一、打开应用
便携版：完整解压 ZIP，在解压后的文件夹里打开 Shiying.exe。不要只移动 exe 文件。
安装版：打开 Shiying-0.1.0-Setup.exe，选择安装位置。安装后可从桌面或开始菜单打开。

二、保存视频
1. 复制单条视频的链接，也可以复制整段分享文案。
2. 粘贴到拾影，点击「解析视频」。
3. 点击「更改」选择保存文件夹，选择可用画质。
4. 点击「下载到文件夹」。完成后可查看文件。

默认使用包含声音的单文件视频。若平台提供分离音画或需要更高画质，在「连接设置」下载高清合并组件。
YouTube 所需的约 2 MB 轻量支持组件已包含在应用中，无需另装大型运行环境。高清合并组件约 30 MB，按需下载一次，解压后约 84 MB。

三、无法解析时
- 检查链接是否能在浏览器正常播放。
- TikTok / YouTube 需要能访问对应平台的网络。代理可在「连接设置」填写，留空使用系统网络配置。
- 平台要求登录时，选择浏览器导出的 Netscape 格式 cookies.txt。文件只在本机读取，读取到的登录信息仅用于对应视频平台的请求。
- 不支持正在进行的直播、播放列表、DRM 视频和平台验证页面。
- 快手使用公开分享页解析，页面数据结构改变或风控可能导致失败。
- 网站可能更改解析方式，本版本不保证任意链接始终可用。

四、轻量与数据位置
应用使用系统 Microsoft WebView2，不捆绑浏览器，不需要安装 Python 或 Node.js。
需要 .NET Framework 4.8（当前 Windows 10/11 通常自带）和 WebView2 Runtime。
若系统缺少 WebView2，应用启动时会提示打开微软下载页面。
便携版：设置、最近 20 条下载记录、可选组件和界面缓存放在同目录 Data 文件夹。
安装版：上述数据放在 %LOCALAPPDATA%\Shiying。
视频保存到你选择的文件夹。取消下载时会保留已下载的片段，重试相同链接可继续。
安装版可通过 Windows「已安装的应用」或安装目录 Uninstall.exe 卸载，视频和用户数据会保留。
